# Project Showcase

This section highlights a curated selection of technical initiatives and engineering leadership milestones from my career. Each example reflects a blend of hands-on development, system design, and team management that shaped my approach to building scalable, resilient products.

### **Frontend Deployment Infrastructure Rebuild**
**Role:** Engineering Manager  
**Tech:** React, Docker, Terraform, AWS App Runner, GitHub Actions  

Rebuilt the frontend deployment process into containerized preview environments, allowing Product and Design to validate features earlier in the release cycle.  
* Improved release reliability and rollback confidence across distributed teams.  
* Adopted structured Scrum practices, replacing an ad hoc Kanban approach to improve communication cadence and stakeholder alignment.  
* Resulted in more predictable sprint delivery and clearer expectation-setting for engineers.

### **Microservices Consolidation and Monorepo Adoption**
**Role:** Engineering Manager  
**Tech:** TypeScript, AWS Lambda, API Gateway, Terraform, RDS, GitHub Actions  

Unified fragmented backend services into a shared monorepo and centralized RDS instance, simplifying data access and CI/CD management.  
* Increased developer velocity and reduced dependency friction across multiple teams.

* Strengthened communication with Product and Platform teams, aligning backend scalability work with business outcomes.

**Role:** Senior Fullstack Engineer → Engineering Manager  
**Tech:** Java, TypeScript, AWS Lambda, Terraform, Jest  

Re-architected a legacy Java monolith into an AWS Lambda–based microservice written in TypeScript, improving scalability, reliability, and observability.
